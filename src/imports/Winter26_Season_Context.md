# Winter26 Season - context

_This document summarizes key points of Winter 2026 Season of IBM AI Racing League._

---

## Motto

Code. Collaborate. Conquer.

Intelligent Racing.

## Team
Team size 1 - 3 members per team. 3 is maximum.

Students of 18 years and above (highschool or college/university).

## Registration
Each team member has to register individually. 

Registration form is done via MS Forms.

## Submission requirements
- Each member has completed the 5 min course "How IBM Bob and AI Tools Are Changing the Way Solutions Are Built" ([https://skills.yourlearning.ibm.com/activity/ALM-COURSE_4076311?ngo-id=0302](https://skills.yourlearning.ibm.com/activity/ALM-COURSE_4076311?ngo-id=0302))
- Team submits a link to public gitHub repository containing:
  - python code for the formula
  - livery for the formula for mass start race
  - up to 2 minute team video (introduce team, explain approach, make a difference)
  - links to 3 posts on social media about their journey through the competition (instagram, facebook, linkedin)

Submission is done via a MS Forms.  

## Racing track and evaluation
Racing track is ramdomly selected for Solo Qualification as well as Mass Start.

Each formula code will be checked for harmful code (deliberately crashing into opponents etc.) and can be disqualified once this code is found.

#### Phase 1 - Solo Qualification
Each formula runs individually on the selected track for 3 laps. 

Best 32 times qualify for the mass start.

#### Phase 2 - Mass Start
Each mass start will have 8 cars and will run on a randomly selected track for Phase 2.

Four groups with 8 formulas each will be formed using snake-seeding.

Heats (4 races × 8 cars for 3 laps) - The top 4 from each heat advance.

| Heat A | Heat B | Heat C | Heat D |
| :--- | :--- | :--- | :--- |
| Seed 1 | Seed 2 | Seed 3 | Seed 4 |
| Seed 8 | Seed 7 | Seed 6 | Seed 5 |
| Seed 9 | Seed 10 | Seed 11 | Seed 12 |
| Seed 16 | Seed 15 | Seed 14 | Seed 13 |
| Seed 17 | Seed 18 | Seed 19 | Seed 20 |
| Seed 24 | Seed 23 | Seed 22 | Seed 21 |
| Seed 25 | Seed 26 | Seed 27 | Seed 28 |
| Seed 32 | Seed 31 | Seed 30 | Seed 29 |

Semifinals (2 races x 8 cars for 3 laps) - The top 4 from each semi-final advance. 

Grand Finals (1 race x 8 cars for 5 laps).


## Technology to be used
- The Open Racing Car Simulator (TORCS)
- Python IDE (IBM Bob - VSCode fork)

You can run TORCS natively on Windows or Linux and through WINE on MacOS.

Alternatively you can use pre-made image with everything baked-in (TORCS, patches, IBM Bob).
